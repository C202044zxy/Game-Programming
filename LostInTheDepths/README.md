# Lost in the Depths

A small 2D underwater game built in **Unity 2022.3.62f1**. You control a fish
swimming through an open, rocky reef: collect all the glowing pearls while
avoiding the patrolling sharks. Swim into a shark and the level restarts.

## Controls

| Action | Keys                         |
|--------|------------------------------|
| Swim   | `WASD` or the arrow keys     |

Collect every pearl (shown as `Pearls n / total` in the top-left) to clear the
level. The exit / win flow lands in a later milestone.

## How it's built

The game is assembled entirely from code at runtime. The scene
(`Assets/Scenes/GameScene.unity`) contains a single `GameBootstrap` component;
on `Start` it builds the cave, ambience, HUD, player, pearls, sharks and follow
camera. There are no prefabs or manual Inspector wiring to maintain.

See [`Assets/Scripts/README.md`](Assets/Scripts/README.md) for a per-class
breakdown of the gameplay code and the startup flow.

## Project layout

```
LostInTheDepths/
├── Assets/
│   ├── Scenes/
│   │   └── GameScene.unity ...... the one scene; holds a GameBootstrap
│   ├── Scripts/
│   │   ├── *.cs ................. gameplay code (see Scripts/README.md)
│   │   └── README.md ........... per-class documentation
│   └── Resources/
│       └── Art/ ................ runtime-loaded sprites (PNG)
├── Tools/
│   └── gen_art.py .............. regenerates the authored sprites (Pillow)
├── Packages/manifest.json ...... package dependencies
├── ProjectSettings/ ............ Unity project settings
└── CREDITS.md .................. art / engine / package attribution
```

`Library/`, `Logs/`, `Temp/`, `obj/` and `UserSettings/` are local Unity
caches and are not source — they are regenerated by the editor.

## Art

Sprites live in `Assets/Resources/Art/` and are loaded by `GameArt.cs`. Some are
CC0 (Kenney Fish Pack), others are authored for this coursework; the shark, rock
and seagrass are generated by `Tools/gen_art.py`. Full attribution is in
[`CREDITS.md`](CREDITS.md). If a sprite ever fails to load the game falls back to
a procedural shape from `RuntimeSprites.cs`, so it always runs.

To regenerate the authored art (requires Python + Pillow):

```sh
python Tools/gen_art.py
```

## Dependencies

Key Unity packages (full list in `Packages/manifest.json`):

- `com.unity.cinemachine` — the follow camera (`CameraRig`)
- `com.unity.ugui` — the score HUD
- `com.unity.2d.sprite`, `com.unity.modules.physics2d` — 2D rendering & physics
